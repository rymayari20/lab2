# Hacker News Job Scraper

Un outil Python pour analyser les offres d'emploi du fil "Who is hiring?" sur Hacker News.

## Fonctionnalités

- Scraping des commentaires du fil Hacker News
- Analyse des technologies les plus demandées
- Visualisation des données avec Matplotlib
- Nettoyage automatique du texte

## Technologies Utilisées

- Python 3
- BeautifulSoup 4
- Requests
- Matplotlib
